# Goradio

**Interactive web interfaces powered by Go.**

Goradio is a developing framework for exposing Go and Python functions through
browser-based interfaces. This revision establishes the project repository;
see the current [main branch](https://github.com/ThowiLabs/Goradio)
for the latest source code, installation instructions and examples.

## Project

The framework aims to provide a Go-first HTTP runtime and a familiar Python
API for creating interactive web interfaces.

## Development

Source code and runnable examples are introduced in subsequent revisions.
Consult the documentation accompanying the version you intend to use.
